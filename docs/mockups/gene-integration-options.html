三个方案共用的前置步骤（无论你选哪个都要做）

1. 构建 17M 紧凑 bundle：用 build_equal_study_gene_chunks.py 把 1.24 GB 的 overall.equal_study.summary.h5ad 转成浏览器块。环境已就绪 （miniconda3/envs/scbrain，h5py 3.15.1 / numpy 2.2.6）。按 44M 版的 14.95% 压缩率外推， 预计产出约 150–190 MB、约 1,232 个 chunk。

2. 校验：跑 validate_equal_study_gene_chunks.py --verify-all-hashes 做源码校验和与量化误差比对。

3. 决定 44M 版去留：是整体替换，还是两版并存由用户在界面上切换。
